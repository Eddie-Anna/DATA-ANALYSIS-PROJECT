# Excel Data Analysis Portfolio

# Overview
This repository showcases a real world dataset that was transformed and analyzed in Excel.  
The original rough data was cleaned, structured into a tabular format, and analyzed to generate meaningful insights.  
The results are presented in a dashboard to visualize key trends and metrics.

# Project Steps

1. Data Cleaning
   Removed duplicates and irrelevant entries
   Standardized formats for consistency  
   Corrected missing or inconsistent data

2. Data Transformation
   Converted the raw sheet into a structured tabular format
   Organized data into rows and columns suitable for analysis

3. Calculations
   Performed necessary calculations (e.g., totals, averages, percentages)  
   Created derived metrics to highlight trends.

4. Visualization / Dashboard
   Built an Excel dashboard to visualize key findings  
   Included charts, summaries, and pivot tables for interactive analysis.

# Tools & Skills
Microsoft Excel  
Pivot tables and charts  
Data cleaning and transformation  
Calculations and derived metrics  
Dashboard creation.

# How to Use
1. Download the files  
2. Open the `.xlsx` in Excel to explore the dashboard and formulas  
3. Open the `.csv` to view the cleaned tabular dataset.

# Notes
CSV contains cleaned, tabular data only
Dashboard visuals are Excel specific and are in the `.xlsx` file
